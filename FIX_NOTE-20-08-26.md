# Fix note

The workplace phrase cards currently show placeholder text under **IN IT / WORKPLACE** and **EXAMPLE / USAGE** instead of phrase-specific explanations.

Each entry should instead contain:

- Literal meaning
- Actual IT/workplace meaning
- Example/usage in a realistic IT context
- Relevant category

Example:

**We're running behind.**

**In IT / workplace:** The team or task is behind the planned schedule.

**Example / usage:** “We're running behind because testing took longer than expected.”
